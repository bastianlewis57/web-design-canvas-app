## What Is Design Canvas?

Design Canvas centers on an HTML canvas workspace you open in the browser. Instead of installing a heavy desktop suite, you get a place to sketch, place, and refine visual ideas in a web-friendly format.

Designers, developers, learners, and anyone who prefers a light HTML-oriented canvas can use it. As long as a compatible browser can reach the project, you can start working without a platform-specific install package.

## Installation

Clone the repository:

```bash
git clone https://github.com/bastianlewis57/web-design-canvas-app.git
cd REPO
```

Load the main HTML entry in a current browser, or expose the folder with a local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

You can also jump straight to the hosted build:

[Open Design Canvas](https://bastianlewis57.github.io/web-design-canvas-app/)

## Usage

1. Launch either the hosted copy or your local checkout.
2. Start from the canvas workspace and block out a design.
3. Shape the layout through the HTML-based files that ship with the project.
4. After editing files on disk, reload the browser when you need a fresh view.
5. If you are customizing the repo, keep your work on a branch or a separate working tree.

When developing locally, start the server at the repository root so paths resolve the same way every time.

Make sure you are using the hosted URL or serving from the project root. Locally, start the HTTP server and open the localhost address it prints instead of a partial path into the tree.
